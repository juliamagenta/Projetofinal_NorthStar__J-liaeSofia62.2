# Bandeiras

Imagens PNG de 320 pixels de largura, baixadas do [Flagpedia / FlagCDN](https://flagpedia.net/download/api).
Os arquivos são servidos localmente, com as proporções originais.

| País | Arquivo | Origem |
| --- | --- | --- |
| Canadá | ca.png | https://flagcdn.com/w320/ca.png |
| Estados Unidos | us.png | https://flagcdn.com/w320/us.png |
| Austrália | au.png | https://flagcdn.com/w320/au.png |
| Irlanda | ie.png | https://flagcdn.com/w320/ie.png |
| Reino Unido | gb.png | https://flagcdn.com/w320/gb.png |
| Alemanha | de.png | https://flagcdn.com/w320/de.png |

O fornecedor [disponibiliza as imagens para uso comercial e não comercial](https://flagpedia.net/download/images), com base em arquivos do Wikimedia Commons.
